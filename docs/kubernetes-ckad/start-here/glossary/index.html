Glossary

Docs: Kubernetes glossary · Namespaces · Objects

One line per term. Follow the link for the full explanation.

Connecting​

TermDefinitionMore
ClusterA control plane plus the nodes it manages. One API endpoint.Architecture
kubeconfigThe YAML file on your laptop that tells kubectl which clusters exist and how to log in.kubeconfig in 5 lines
ContextA named triple in kubeconfig: cluster + user + default namespace.Context vs Namespace
Current contextThe context kubectl uses when you don't pass --context.Standard lab setup

Organization​

TermDefinitionMore
Imperative vs declarativeImperative commands (run, create, scale) change the cluster directly. Declarative apply -f makes it match a file.Generate, edit, apply
NamespaceA named partition inside a cluster for names, access and quotas.What a namespace isolates
Namespaced vs cluster-scopedNamespaced kinds (Pod, Service) live in a namespace. Cluster-scoped kinds (Node, PV, ClusterRole) don't. List them with kubectl api-resources --namespaced=true or =false.Architecture

Machinery​

TermDefinitionMore
Control planeThe components that decide: API server, etcd, scheduler, controller manager.Components
API serverThe front door. Validates and stores every read and write. The only client of etcd.Components
etcdThe key-value store holding every object's spec and status.Components
SchedulerPicks a node for each Pod that has none.Components
Controller managerOne process running the built-in controllers (ReplicaSet, Deployment, Job…).Components
NodeA machine (VM, server, or a Docker container in kind) that runs Pods.Components
kubeletThe agent on every node. Starts the Pods bound to it and reports their status.Components
Container runtimePulls images and runs containers for the kubelet (containerd, CRI-O).Components
ControllerA loop that watches objects and acts to make actual state match desired state.Controllers

Describing state​

TermDefinitionMore
Resource / kindA type the API serves (kind: Deployment). "Resource" is its plural API name (deployments).API groups
ObjectOne stored instance of a kind, such as Deployment web in lab1.Four top-level fields
ManifestA YAML file describing one or more objects, applied with kubectl apply -f.Where a change lives
spec vs statusspec is what you want, written by you. status is what exists, written by controllers.Where a change lives
LabelA key-value pair on an object, used for selection (app: web).Where labels link
SelectorA label query that picks objects. The only way a Service or ReplicaSet finds its Pods.Where labels link
AnnotationA key-value pair for tools and humans. Never used for selection.Annotations

Workloads & networking​

How these fit together: the object map.

TermDefinitionMore
PodOne or more containers sharing a network and volumes. The smallest thing you run.Pods
ReplicaSetKeeps N copies of one Pod template running. Owned by a Deployment.Deployments
DeploymentManages ReplicaSets to roll out new Pod templates and roll back.Deployments
ServiceA stable name and IP in front of the Pods its selector matches.Service types
EndpointSliceThe current list of Ready Pod IPs behind a Service. Empty means no traffic.Life of an apply

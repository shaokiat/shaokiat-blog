Glossary

Docs: scikit-learn glossary · Google ML glossary

One line per term. Follow the link for the full explanation.

Framing​

TermDefinitionMore
Snapshot dateThe moment you freeze time: features only from before it, the label only from after it.The snapshot date
Label windowThe period after the snapshot date in which the outcome is observed (30 days here).The label
Base rateThe share of positive rows: 3% of machines fail per window.Start with the target
BaselineThe score of a simple strategy the model must beat, such as the CMMS rule.Baseline first

Data​

TermDefinitionMore
LeakageTraining data containing information the model won't have at prediction time. Scores too good, then collapses.The leakage bug
MCAR / MAR / MNARMissing completely at random; explained by other columns; depends on the missing value itself.Missing values
Missing indicatorA 0/1 column recording that a value was imputed, so the gap's signal survives.Missing values
Target encodingReplacing a category with its mean target. Must be out-of-fold or it leaks.Encoding categoricals
PipelineOne fitted object holding every preprocessing step plus the model.The pipeline pattern
Permutation importanceThe score drop when one column is shuffled. No drop means the model ignores it.Selecting features
SHAPPer-prediction attribution of a score to each feature. Describes the model, not causes.Explaining the model

Validation​

TermDefinitionMore
Cross-validationRotating which fold is held out, so every row validates once.Cross-validation
Time-based splitTrain on earlier periods, validate and test on later ones.Choosing the validation split
Bias–varianceUnderfitting (too simple) vs overfitting (too flexible).Bias–variance trade-off
RegularisationA penalty on complexity: L1 zeroes weights, L2 shrinks them.Regularisation
Early stoppingStop adding trees or epochs when the validation score stops improving.Gradient boosting

Metrics​

TermDefinitionMore
Precision / recallShare of flags that were right / share of positives that were flagged.Evaluation metrics
PR-AUCPrecision averaged over all recall levels. The metric for rare positives.Evaluation metrics
ROC-AUCHow often a random positive outranks a random negative. Flattering on rare positives.Evaluation metrics
ThresholdThe score above which a row is flagged. Set by the cost of misses vs false alarms.Evaluation metrics
RMSE / MAETypical miss size; RMSE weights big misses more.Regression metrics

Models​

TermDefinitionMore
BaggingMany models on random subsets, averaged. Cuts variance.Bagging vs boosting
BoostingModels in sequence, each fitting the last one's errors. Cuts bias.Bagging vs boosting
CalibrationWhether a score of 0.3 really means a 30% chance.Logistic regression
Class weightUp-weighting the rare class in the loss (class_weight, scale_pos_weight).Handling class imbalance

Production​

TermDefinitionMore
Training/serving skewFeatures computed differently in serving than in training. Silent decay.Training/serving skew
Covariate driftInput distributions shift after launch.Monitoring and drift
Concept driftThe same inputs now mean a different outcome.Monitoring and drift
Control groupA random slice that doesn't get the intervention, for clean labels and causal impact.Proving impact

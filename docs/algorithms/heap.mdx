## Time Complexity

| Operation | Big-O | Python `heapq` |
| --- | --- | --- |
| Peek min | O(1) | `heap[0]` |
| Push | O(log(n)) | `heappush` |
| Pop min | O(log(n)) | `heappop` |
| Push then pop | O(log(n)) | `heappushpop` |
| Build from list | O(n) | `heapify`, not n pushes |
| Search / remove arbitrary | O(n) | Use lazy deletion instead |

`heapq` is a **min**-heap only. For a max-heap, push `-x`. For objects, push tuples `(priority, tiebreak, item)`: without the tiebreak, equal priorities make Python compare the items and raise.

## Common Approaches to Heap Questions

| Pattern | Use when | Cost | Example |
| --- | --- | --- | --- |
| Top-k with a size-k heap | k largest/closest from n items, or a stream | O(n log k) | [K Closest Points](./arrays.mdx#k-closest-points-to-origin), [Kth Largest](https://leetcode.com/problems/kth-largest-element-in-an-array/) |
| Two heaps | Running median, or balancing two halves | O(log n) per add | [Find Median from Data Stream](https://leetcode.com/problems/find-median-from-data-stream/) |
| K-way merge | Merge k sorted lists/arrays; kth smallest in a sorted matrix | O(N log k) | [Merge k Sorted Lists](https://leetcode.com/problems/merge-k-sorted-lists/) |
| Greedy scheduling | Always run the most urgent or most frequent next | O(n log n) | [Task Scheduler](#task-scheduler), [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/) |
| Shortest path | Dijkstra: pop the closest unsettled node | O(E log V) | [Graphs → Dijkstra](./graph.mdx#dijkstra) |

### Top-k: keep the opposite heap

For the k **largest**, keep a **min**-heap of size k: its root is the smallest of the winners, so it's the one to evict.

```py
import heapq

def kthLargest(nums, k):
    heap = []
    for n in nums:
        heapq.heappush(heap, n)
        if len(heap) > k:
            heapq.heappop(heap) # drop the smallest; the k largest remain
    return heap[0]
```

`heapq.nlargest(k, nums)` does the same in one line.

### Two heaps: running median

A max-heap holds the lower half, a min-heap the upper half. Keep their sizes within one, and the median is at the roots.

```py
import heapq

class MedianFinder:
    def __init__(self):
        self.lo, self.hi = [], [] # lo: max-heap via negation, hi: min-heap

    def addNum(self, num):
        heapq.heappush(self.lo, -num)
        heapq.heappush(self.hi, -heapq.heappop(self.lo)) # largest of lo moves up
        if len(self.hi) > len(self.lo):
            heapq.heappush(self.lo, -heapq.heappop(self.hi)) # rebalance

    def findMedian(self):
        if len(self.lo) > len(self.hi):
            return -self.lo[0]
        return (-self.lo[0] + self.hi[0]) / 2
```

### [Task Scheduler](https://leetcode.com/problems/task-scheduler/)

#### Solution 1: Math Approach
- Case 1: No idle gaps required - answer is length of tasks
- Case 2: Idle gaps required - (maxFreq - 1) * (n + 1) + nMax
  - (maxFreq - 1) - maximum occurences of character with maximum occurences except last occurence
  - (n + 1) - number of elements in each repeated interval `A _ _`
  - nMax - number of characters in last occurence
 
```py
def leastInterval(self, tasks, n):
  store = {}
  for i in tasks:
    store = 1 + store.get(i, 0) # default 0 if not found
  lst = sorted(store.values(), reverse=True)
  maxFreq = lst[0]
  nMax = lst.count(maxFreq)
  caseTwo = (maxFreq - 1) * (n + 1) + nMax
  return max(len(tasks), caseTwo)
```

Time Complexity: `O(n)` for counting tasks.

Space Complexity: `O(1)` for fixed dictionary size of 26 characters.

#### Solution 2: Heap and Queue

:::important Source
[**Explanation**](https://www.youtube.com/watch?v=s8p8ukTyA2I) by NeetCode.
:::

```py
def leastInterval(self, tasks, n):
  count = Counter(tasks)
  maxHeap = [-cnt for cnt in count.values()]
  heapq.heapify(maxHeap)
  
  time = 0 
  q = deque() # pairs of [-cnt, idleTime]
  while maxHeap or q:
    time += 1
    if maxHeap:
      cnt = 1 + heapq.heappop(maxHeap)
      if cnt: # Count not zero: add back to queue with new idleTime
        q.append([cnt, time + n])
    if q and q[0][1] == time:
      heapq.heappush(maxHeap, q.popleft()[0])
  return time
```

Time Complexity: `O(n + m)` where n is len(tasks) and m is length of idle interval.

Space Complexity: `O(1)` for fixed dictionary size of 26 characters.
